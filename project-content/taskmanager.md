# Task Manager

## Overview

Gerenciador desenvolvido em Python para praticar organização de aplicações, manipulação de dados e lógica de programação.

## Problem

Este projeto foi criado como uma forma de desenvolver uma aplicação capaz de organizar e gerenciar tarefas através de uma interface simples.

## Technologies

- Python

## Implementation

A aplicação foi construída em Python e organizada de forma a separar as diferentes responsabilidades do sistema.

## Challenges

Durante o desenvolvimento, alguns dos principais pontos de atenção foram a organização do código e o controle do estado das tarefas.

## What I Learned

Este projeto ajudou a praticar conceitos de Python e organização de aplicações.
